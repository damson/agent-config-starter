# Example skill

The smallest skill that passes `just test`: a name matching its folder, a
non-empty description, numbered steps, and a stopping rule.

## Procedure

1. Copy this folder and rename it after the procedure you keep repeating.
2. Write the trigger into `description:` — it is the only thing that fires it.
3. Replace these steps with the real ones.

## When to STOP

- The task needs judgment the procedure cannot encode — hand back to the user.
